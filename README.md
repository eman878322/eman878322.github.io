A GitHub-Pages-ready personal portfolio website.

## Included
- Home / About / Skills / Projects / Journey / Education / Services / Objective / Contact
- Personal profile photo
- Four selected projects only
- Direct GitHub links for the project repositories
- PlantMDAI live demo link
- Six selected certificates
- Dark / light mode
- Responsive mobile navigation
- Lightweight scroll reveal animations

## Publish on GitHub Pages
Recommended repository name:

`eman878322.github.io`

Upload the contents of this folder to the repository root, commit to the `main` branch, then go to:

**Settings → Pages → Build and deployment → Source: GitHub Actions**

The included workflow will deploy the site automatically.
